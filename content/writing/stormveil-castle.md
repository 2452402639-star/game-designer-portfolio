## 00 / CORE THESIS

### 核心判断：史东薇尔真正强在哪

史东薇尔城最值得学的，不是“它有很多路”，而是它让空间结构比玩家当下理解到的更复杂，同时又让玩家当下需要理解的信息足够少。

如果把完整路线摊开看，它接近一张立体蜘蛛网：屋顶、墙外、仓库、教堂、地下、落点、梯子、单向门和捷径不断交错。但玩家第一次进入时，并不会同时处理这张网。设计通过可见性、距离、高差、亮度、敌人、奖励和不可逆成本，让不同路线天然形成优先级。

![史东薇尔设计逻辑的四层抽象](/writing/stormveil-castle/core-thesis-framework.jpg)

*图 1｜本文对史东薇尔设计逻辑的四层抽象。*

> 结构负责提供自由，认知负责安排顺序；节奏让探索持续有张力，回环让复杂空间最终变成记忆。

这也决定了本文后面的分析方向：不再问“这里一共有几条路”，而是问“玩家什么时候看见这些路、为什么更可能先走其中一条、走完之后如何重新理解旧空间”。

## 01 / ROLE IN THE GAME

### 关卡定位：从开放世界切换到高密度箱庭

史东薇尔首先是一次“探索节奏换挡”。它把玩家从长距离、低密度的开放世界移动，切换到短反馈、高信息密度、强垂直关系的遗迹探索。

![史东薇尔城入口坡道与仰视构图](/writing/stormveil-castle/stormveil-entrance.jpg)

*图 2｜入口坡度与仰视构图先把“城堡整体”变成强地标，再把玩家压进高密度空间。*

这里最关键的变化不是地图尺寸，而是反馈周期。进入城堡后，门洞、敌人、道具、岔路、落点和捷径更频繁出现，玩家几乎每走几十秒都要重新读一次环境。于是观察方式也被迫改变：不能再只看远处地标，而要开始看上方、看边缘、看开口、看敌人的朝向。

### 它同时承担“二次教学”

- 风暴鹰把注意力从平面拉到高处，提前训练屋顶区域所需的垂直观察。
- 火药桶与环境危险提醒玩家：场景本身也会参与战斗。
- 失乡骑士把精英敌人的压迫阈值突然抬高，制造第一次明显的记忆峰值。
- 跳跃、落差和外墙路线让玩家重新学习“魂系箱庭 + 可跳跃”之后的导航语言。

> 大型箱庭的入口不只是在“把玩家送进地图”，它还应该告诉玩家：从现在开始，你需要用另一套观察方式来玩。

## 02 / MACRO TOPOLOGY

### 宏观结构：先让玩家知道自己“在哪个区”

复杂地图如果只靠玩家记“每一条路”，认知成本会迅速失控。史东薇尔更有效的做法，是先把城堡拆成若干具有明显身份的区域，再让复杂路线挂在这些区域之间。

![史东薇尔城区域拓扑抽象](/writing/stormveil-castle/macro-topology.jpg)

*图 3｜区域拓扑抽象：先建立区域节点，再处理房间与支路。*

玩家通常不会精确记住每一段转角，但会记住“我刚从壁外栈道进了仓库”“我现在在城墙塔上方”“下一片明显区域是屋顶或教堂”。这种区域化记忆允许局部结构很复杂，只要区域之间的连接仍然有层级。

### “持续向上”是一个很重要的宏观动机

史东薇尔的很多支路会横向绕、向下掉、再爬回来，但整体推进仍经常让玩家感受到“我在往更高、更深、更接近城堡核心的位置走”。这个宏观趋势很简单，却能承载大量局部绕路。局部可以复杂，宏观最好简单。

### 白盒阶段先问三件事

每个区域分别回答：

1. 这个区最容易被记住的视觉 / 玩法主题是什么？
2. 它与哪些区域连通？
3. 玩家第一次进入时，最可能从哪个接口进、从哪个接口出？

## 03 / ROUTE WEIGHT

### 路线控制：不是封路，而是改变“第一选择”的概率

史东薇尔的大多数岔路并没有被硬性禁止，但它们也绝不是同等吸引。真正的控制发生在“哪条路更像现在应该走的路”。

![史东薇尔城路线权重模型](/writing/stormveil-castle/route-weight-model.jpg)

*图 4｜路线权重模型：通过多维优势叠加，让主路更容易成为首选。*

可以把每一个出口理解成一个“候选选项”。玩家做决定时，会无意识地综合多个条件：是否已经看见、离自己多近、是不是同层、开口够不够宽、亮不亮、有没有奖励、敌人危险不危险、走下去能不能回头。设计师真正能做的，是调整这些条件的组合。

| 维度 | 提高初见优先级 | 降低初见优先级 |
| --- | --- | --- |
| 可见性 | 先让玩家看见出口、远景或目标 | 让分支被遮挡，稍后才显露 |
| 距离 / 层级 | 近、同层、顺着前进方向 | 远、跨层、需要回头 |
| 空间感受 | 宽、亮、开口明确 | 窄、暗、需要钻入或下坠 |
| 风险 | 弱敌、可撤退、可回头 | 强敌、深落差、不可逆 |
| 收益 | 可见道具、动态目标、明确地标 | 收益未知或需要先承担成本 |

## 03.1 / SOFT GUIDANCE

### 软引导：单个信号很弱，多个信号同向就会很强

史东薇尔很少依赖单一的巨大提示。更常见的是多个微弱信号同时指向一个方向：出口朝向远景，门洞更亮，赐福或道具发光，巡逻敌人在移动，NPC 从某个方向发声，地形开口也刚好更宽。每一个信号单独看都不强，但叠起来之后，玩家会非常自然地把某条路当成“正常推进”。

| 信号类型 | 常见表现 | 真正控制的东西 |
| --- | --- | --- |
| 构图 / 朝向 | 坡道抬镜头、出口正对远景、柱体 / 边线指向落点 | 第一眼看哪里 |
| 光与色 | 赐福、火把、门洞亮部、道具光点 | 背景里什么最先被注意 |
| 运动 / 声音 | 巡逻敌人、飞行敌人、NPC 呼唤、战斗音效 | 静态场景中谁抢占注意力 |
| 开口 / 遮挡 | 只开放需要的观察孔、用墙体 / 物件挡掉部分信息 | 现在能看到多少 |
| 空间属性 | 同层、近、宽、亮；或下坠、狭窄、黑暗 | 哪条路更像“正常路线” |

### 自由感为什么还能保留？

因为设计控制的是“吸引力”，不是“许可权”。玩家仍然可以逆着引导跳下去、绕远路、钻进黑暗支路；只要这些路线依然成立，自由就是实打实的。设计师只是把最容易成功的初见体验放在概率最高的位置。

> 真正需要锁死的顺序，才交给单向门、不可逆落差或封闭连接；其余大多数情况，优先用空间条件改变首选概率，而不是把路直接封掉。

## 04 / NONLINEAR, BUT READABLE

### 非线性结构，顺序化初见

![史东薇尔城屋顶区域的多个落点与表面](/writing/stormveil-castle/nonlinear-rooftop.jpg)

*图 5｜屋顶区域同时暴露多个落点与表面，但它们的“选择成本”并不相同。*

屋顶最能说明这件事。玩家一眼就能看到很多可跳的表面、断柱、天井、步道和相邻屋檐，但“看得见”不等于“现在就会走”。不可逆下落会让人犹豫，深落差会提高失败成本，距离和高差会自然延后某些分支；反过来，同层、开阔、近距离、带可见奖励的路线更容易成为首选。

### 信息不是越多越好，而是要分批释放

如果第一次到屋顶就把所有路线都做得同样明显，玩家看到的不是自由，而是噪音。史东薇尔更接近“先把当前需要处理的 2～3 个选项做清楚，再让新的选项随着位置变化逐步出现”。非线性拓扑可以很复杂，但初见时同时需要判断的候选路线不能无限增加。

> 自由度是结构属性；迷不迷路是认知属性。地图可以非线性，但玩家在每一个瞬间仍然应该有清晰的局部判断。

## 05 / VERTICALITY & LOOPS

### 垂直空间与回环：让复杂地图最终在脑中闭合

史东薇尔的垂直感并不是“多盖几层楼”，而是不断打破标准楼层，让玩家在建筑内部、外墙、夹层、屋顶和落点之间切换。

壁外栈道的价值就在这里：它把玩家从建筑内部暂时拉出去，让玩家从外侧重新看刚才经过的楼层。夹层与落点又打断连续楼梯，让“二楼、三楼”的规整概念变成“我正在建筑外壳、内部和表面之间穿行”。到了屋顶之后，路线语言进一步从“房间—楼梯”变成“表面—断口—落点”。

![史东薇尔城回环与捷径的认知收益](/writing/stormveil-castle/vertical-loop-model.jpg)

*图 6｜回环不是单纯省路，它还要重新解释玩家已经走过的空间。*

### 好的捷径有两种收益

- **功能收益：**死亡后少跑一段，降低重复劳动。
- **认知收益：**捷径打开的一刻，玩家看见旧门、旧坡道、旧赐福，突然理解“原来我已经绕回这里上方 / 侧面”。

评审捷径时多问一句：它除了省时间，有没有在打开时告诉玩家“我到底连回了哪里”？只解决跑图效率，是功能性捷径；能让地图在脑中闭合，才是高质量回环。

## 06 / ENCOUNTER DESIGN

### 遭遇设计：敌人也是关卡组件

史东薇尔的敌人经常同时承担四种工作：教新规则、改变视线、制造记忆峰值、切分空间。

![史东薇尔城失乡骑士初见](/writing/stormveil-castle/banished-knight.jpg)

*图 7｜失乡骑士初见：受限视觉 + 强听觉提示 + 突进压力，把一个小房间做成强记忆点。*

| 案例 | 主要设计功能 | 为什么有效 |
| --- | --- | --- |
| 三士兵初见 | 分阶段拉仇恨，教玩家读 AI 与站位 | 不是三人同时压上，而是压力逐步升级，学习成本可控 |
| 风暴鹰 | 把注意力抬到上方 | 先在轮廓清晰的位置展示，再逐步加入伏击和复杂站位 |
| 失乡骑士 | 制造高压记忆峰值 | 黑暗减少视觉信息，声音和突进把安全距离迅速压缩 |
| 正门大场地 | 用仇恨区切出“隐形战斗房间” | 地形、距离与朝向避免整片敌群一次性进入战斗 |

### 开放场地 ≠ 一个巨大的仇恨池

一个场地视觉上可以很开放，但 AI 上仍应该被拆成多个可控遭遇。越是大空间，越要检查“玩家向前一步会同时激活几组敌人”。如果视觉上是大场景，仇恨上也是一个大整体，难度会突然变成失控；如果用障碍、射界、距离和朝向做分区，就能保留开放感，同时控制压力。

## 07 / PACING

### 节奏：压力来自空间和信息，不只来自敌人数量

把关卡节奏理解成“打怪—休息—再打怪”太窄了。史东薇尔更值得学的是：空间宽窄、信息多少、战斗强度、探索成本和反馈密度同时在变化。

![史东薇尔城中分段出现的危险](/writing/stormveil-castle/pacing-example.jpg)

*图 8｜弯道、遮挡与远程火力让危险分段出现，而不是一次把全部威胁摊给玩家。*

| 节奏维度 | 释放 / 低压 | 压迫 / 高压 |
| --- | --- | --- |
| 空间 | 宽阔、远景、可观察 | 狭窄、拐角、夹层、走位受限 |
| 信息 | 目标可见、路线明确 | 遮挡、黑暗、下一段未知 |
| 战斗 | 单怪、弱敌、巡逻 | 精英、伏击、多方向火力 |
| 探索 | 同层近路、可回头 | 下坠、长支路、多分支 |
| 反馈 | 赐福、奖励、捷径、视野打开 | 连续推进、风险累积、资源消耗 |

一个很典型的节奏链条是：窄 / 暗让玩家提高警惕 → 突然打开视野给远景和方向 → 进入战斗把注意力拉回局部 → 奖励和捷径释放压力 → 新的遮挡再次收紧信息。这样的换挡比单纯“多放几个怪”更稳定，也更容易形成层次。

## 08 / REWARD & EXPLORATION

### 奖励与支路：奖励不只是“回报”，还是导航工具

史东薇尔里很多道具光点并不只是“给玩家东西”。它们还在把玩家拉到某个位置、让玩家朝某个方向看，甚至提前教一个危险规则。

当一个奖励放在木台边缘时，玩家为了拿它会自然走到边缘；如果木台只能从某一侧上去，玩家的站位和镜头方向也被一起控制。到达之后，下一片屋顶或新的落点刚好进入视野。于是“趋利”这个最自然的玩家动机，被转化成了一次无 UI 的导航。

### 支路为什么会觉得“值得走”？

| 阶段 | 玩家需要得到什么 | 设计目的 |
| --- | --- | --- |
| 入口 | 一个明确诱因：奖励、地标、异常声音、危险悬念 | 让玩家愿意偏离主线 |
| 过程 | 和主路不同的独特体验 | 让支路不是单纯绕远 |
| 末端 | 收益、视野、强信息或空间解释 | 兑现探索动机 |
| 结束 | 明确到头、回到旧区或打开捷径 | 给认知上的结束感 |

危险教学也可以借用奖励。比如新机关第一次出现时先单独展示，再用光点让玩家在安全边缘观察它；等规则被理解之后，再把两个机关、敌人或狭窄空间组合起来。这样后续失败更像“规则升级”，而不是毫无信息地被阴。

> 支路最低闭环：有理由进去 → 过程中有独特体验 → 末端有兑现 → 玩家知道这条路已经结束或连接回哪里。缺一项，支路就很容易只剩“耗时间”。

## 09 / TRADE-OFFS

### 设计代价：复杂度不是免费的

史东薇尔强的地方，也正是它最容易产生问题的地方。真正值得学习的分析不能只讲“为什么好”，还要讲“它为什么敢承担这些代价”。

| 风险 | 为什么会发生 | 玩家代价 | 什么时候可以接受 |
| --- | --- | --- | --- |
| 回环点不回到原分叉 | 为了强化错层和空间真实性 | 补探索时需要重复较长路径 | 首次体验收益明显，且回跑时间仍可耐受 |
| 不可逆落点多 | 用高差制造路线优先级和立体感 | 玩家担心错过内容，产生犹豫 | 后续回访路径清楚，区域有明确收束 |
| 高层支路过密 | 屋顶网络承担探索深度 | 记忆成本上升，容易忘记漏点 | 强地标、区域主题和宏观方向足够清晰 |
| 软引导依赖玩家习惯 | 不用 UI 强制提示 | 少数玩家可能完全走偏 | 走偏仍然能形成有效体验，不会硬性卡死 |

### 最不该复制的东西

如果只复制“多岔路 + 多高差 + 多单向落点”，却没有同时投入足够的引导、收束、回环、区域辨识和敌人分区，得到的通常不是史东薇尔，而是一座难读的迷宫。

> 复杂度本身没有价值，能被玩家理解、记住并在第二次探索时重新利用的复杂度才有价值。

> 当一段复杂路线带来的“初见惊喜 / 空间记忆 / 重玩价值”不足以覆盖它制造的“迷路 / 补漏 / 重复跑图”成本时，就应该减复杂度，而不是继续加引导补丁。

## 10 / WORKFLOW

### 可复用方法：箱庭白盒怎么开始

![面向原型阶段的箱庭关卡白盒工作流](/writing/stormveil-castle/whitebox-workflow.jpg)

*图 9｜面向原型阶段的箱庭关卡工作流。*

1. **画区域拓扑：** 先定 3～6 个区域节点与连接关系。
2. **定宏观动机：** 让玩家始终知道“大概往哪推进”。
3. **给出口加权：** 比较可见、距离、高差、风险、奖励等。
4. **分批释放信息：** 决定哪些支路现在可见，哪些稍后出现。
5. **切战斗仇恨区：** 开放场地也要保证一次只处理可控敌群。
6. **设计回环与补漏：** 捷径既省路，也要解释空间关系。
7. **逆着引导走一遍：** 故意走偏，检查是否仍然形成有效体验。

这套流程的重点，是把“关卡可读性”前置到白盒，而不是等房间和路线全部堆完之后再补箭头、补灯光、补封路。先把关系、顺序和风险想清楚，后面的美术构图与遭遇配置才是在放大已有设计，而不是救火。

### 一个实用的小技巧：给每个出口写一句话

- “我希望玩家第一次看到它时：立刻去 / 记住但先不去 / 暂时完全看不到。”
- “如果玩家现在就走进去，最坏会发生什么？能不能回来？”
- “这条路完成后，玩家对整个区域的理解会不会增加？”
- “如果玩家完全逆着我的引导走，关卡是否仍然能成立？”

原型阶段最重要的不是“路线够不够多”，而是你能不能解释每一条路线为什么现在被看见、为什么现在被选择、为什么值得走，以及走完之后它如何改变玩家对地图的理解。

## 11 / CHECKLIST

### 原型评审清单

下面这份清单可以直接用于 10～20 分钟箱庭路线的白盒评审。

| 检查维度 | 评审问题 |
| --- | --- |
| 宏观目标 | 玩家在任何时刻，能不能用一句话说出“我大概在往哪里走”？ |
| 区域化 | 复杂路线有没有被拆成若干具有明确视觉 / 玩法身份的区域？ |
| 入口构图 | 进入新区的第一眼，有没有明确的局部目标、远景或强地标？ |
| 候选路线 | 同时进入视野的路线有几条？是否真的需要都在这一刻出现？ |
| 路线权重 | 希望的主路是否在“近 / 同层 / 亮 / 宽 / 动态目标 / 奖励”等多个维度占优？ |
| 隐藏信息 | 哪些支路应该现在看见但先不去？哪些应该晚一点才被发现？ |
| 垂直关系 | 高差只是换楼层，还是会改变观察、战斗、风险和回望？ |
| 单向关系 | 每个不可逆落点 / 单向门，是否真的在解决顺序或节奏问题？ |
| 回环价值 | 捷径打开时，玩家能不能理解“我连接回了哪里”？ |
| 战斗分区 | 一个大空间里，玩家一次可能拉到几组敌人？是否可控？ |
| 新敌人教学 | 新单位是否先在低压、信息清晰的条件下展示，再进入组合？ |
| 节奏换挡 | 是否存在宽 / 窄、明 / 暗、信息多 / 少、战斗 / 探索、压迫 / 释放的交替？ |
| 支路闭环 | 支路有没有“诱因—过程—兑现—结束感”？ |
| 重玩价值 | 第一次被软引导之后，第二次是否仍能发现新的有效路线？ |
| 补漏成本 | 错过支路之后，要重复多少路程才能回来？这个成本是否值得？ |

### 使用方式

不要只在会议室里回答。让一个没参与设计的人走白盒，记录他每个岔路为什么选 A 而不是 B，再回头对照你的“路线权重”假设。

### 推荐走两遍

- **第一遍：** 完全按照你预期的“正常玩家”路线走，检查节奏是否顺。
- **第二遍：** 故意逆着引导、优先跳危险支路、回头补漏，检查地图是否仍然自洽。

如果第二遍一走就崩，说明你的自由更像“表面上有路”，而不是一个真正支持不同选择的结构。

## CONCLUSION

### 结语：真正值得带走的不是“蜘蛛网”，而是“优先级”

史东薇尔城的优秀，不在于它把地图做得难以记忆，而在于它能先让玩家只理解一小部分，再通过探索、回望和捷径，把更大的结构逐步交给玩家。

从策划角度看，我更愿意把它总结成四句话：复杂度负责提供惊喜，路线权重负责保证初见可读；遭遇与空间共同负责节奏，回环负责把碎片化经历变成空间记忆。

所以做自己的箱庭时，最先要设计的并不是“多少个房间、多少条支路”，而是信息出现的顺序、路线选择的概率、失败和回访的成本，以及每一次绕路结束后玩家能多理解什么。只要这些关系是清楚的，复杂空间才有资格继续变复杂。

> 让地图比玩家第一眼理解到的更复杂；同时让玩家第一眼需要理解的东西足够清楚。
